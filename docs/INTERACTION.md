# 交互设计

## 工具栏

工具栏跟随选区，优先放在下方，放不下时移到上方。跨屏时由选区重叠面积最大的显示器承载。窄屏保留全部操作，通过水平滚动访问。

- 第一行：选择与标注工具、当前画笔样式、撤销／重做。
- 第二行：OCR／翻译／识图、原文／译文、复制文字、录屏、更多、取消与保存。
- 底部：单行任务反馈；识别期间显示停止按钮，重复请求暂时禁用。

文字 T、取色 C 的小箭头打开截图内选项。文字提供字体、字号、六种常用颜色和阅读背景；取色提供常用倍率。调整通过 preferencesChanged 交给 Application 保存到 Settings。普通画笔的颜色／粗细与马赛克直径用于当前编辑，分别保留。录屏菜单每次从静音开始。

选项用覆盖层的子控件呈现，保持在屏幕内。点击外部关闭并继续原点击。Esc 优先关闭当前下拉框，再关闭工具选项；选项中的 Enter 不保存截图。EditorToolbar 持有浮层的 QPointer，并在销毁前移除应用事件过滤器。

## 马赛克与绘制

马赛克 M 使用圆头涂抹，按下后记录连续轨迹；点击只涂一个圆点，每笔作为一次撤销。独立直径默认为 32，范围为 8～128 逻辑像素。样式按钮只显示粗细，不显示颜色。普通画笔、直线仍使用原有颜色与 1～24 粗细。

路径不吸附到选区边缘；paintMark 按创建时的选区裁切。预览与最终合成采用同一份 Mark 和同一渲染方法，后续扩大选区不会出现隐藏笔迹。通过快捷键切换工具也会关闭旧选项。

## 统一阅读层

TextOverlay 为一个有区域遮罩的阅读控件，用 QTextLayout 保留各段原位排版，并将文字按返回顺序映射到连续字符索引。间隔处不截获画布操作；鼠标按下后可跨空隙拖到下一段。正反向拖选、Shift 延续选择、Ctrl+A、Ctrl+C 和右键复制共享同一份文本。

字体先按原文区域估算，译文沿用；仅在首行字形更高时略微缩小。背景贴合可见文字，不设置各段滚动条。长文字通过右下角 … 就地展开，再点 − 收起；超出屏幕时在展开区滚轮阅读。复制保留完整文字。连续未定位的文字合并到选区旁的阅读块。

原文／译文改变时重建布局并清除选择。仅更新识图描述或背景透明度时保留当前文字选择和展开状态。切换绘图工具隐藏阅读层，点原文／译文可继续阅读。文字与阅读背景不进入图片。

## 识图与键盘

Document.description 非空时，ReadingPanel 自动显示在工具栏附近，优先使用上下方足够的空间。内容变化才重设文本，因此移动工具栏不会清除选字或滚动位置。图片／选区改变后，Document 清除结果，卡片随之消失。

Esc 按焦点逐层处理：下拉框 → 工具选项 → 阅读选择／展开内容 → 活动识别 → 截图。识图卡片中的 Esc 返回画布。输入标注的 Enter 只提交文字，下次 Enter 才确认截图；文字输入完成立即隐藏输入控件。

交互验证使用 editor-check；应用偏好持久化与识别链路使用 lifecycle-check，真实 Wayland 路径见 [开发说明](DEVELOPMENT.md)。
