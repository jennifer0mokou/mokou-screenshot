# 交互设计

## 工具栏与菜单

工具栏跟随选区，优先放在下方，放不下时移到上方；跨屏由选区重叠面积最大的显示器承载。窄屏可横向滚动。

- 第一行：绘图工具、当前笔刷样式、撤销／重做。
- 第二行：识别、原文／译文、复制、录屏、更多与确认操作。
- 底部：任务反馈；识别期间可停止请求。

文字与取色的相邻小菜单调整基本选项并自动记住。普通画笔与马赛克粗细独立。录屏菜单每次从静音开始。点菜单外部关闭并继续原点击；切换工具也会关闭旧菜单。

## 绘制

马赛克为圆头涂抹和点涂，每笔一次撤销；独立直径 8～128，默认 32 逻辑像素。普通画笔／直线为 1～24，可选颜色。

路径按创建时的选区裁切，预览与保存共用 paintMark；后续扩大选区不会出现隐藏笔迹。输入文字使用独立字体、字号和颜色，输入背景不进入图片。

## 阅读与键盘

TextOverlay 将原位排版的各段文字映射到连续字符索引，支持正反向跨框选择、Shift 延续选择、Ctrl+A／C 与右键复制。间隔处不截获画布操作。

字号按原文估算，译文沿用；较高字形仅缩小到能显示首行。长文字点 … 就地展开，再点 − 收起；超出屏幕可滚轮阅读。展开内容优先接收指针操作。未定位的连续文字合并到选区旁。

切换原文／译文重建布局并清除选择，更新描述或背景保留阅读状态。切换绘图工具隐藏文字层，点原文／译文继续阅读。识图结果自动跟随工具栏，图片或选区改变时清除；OCR、译文和描述按各自设置分别失效。

Esc 逐层处理下拉框、工具选项、文字选择／展开、识别请求和截图。识图卡片的 Esc 返回画布。输入文字的 Enter 只提交标注，下次 Enter 才保存；工具选项中的 Enter 不保存截图。
