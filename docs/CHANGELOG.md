# 版本记录

## 0.4.2 · 2026-10-26

- 整理首次 GitHub 源码发布：MIT、第三方许可、贡献入口、Fedora CI 与发布流程。
- 检查使用 CMake 发现的系统 Python，去除固定本机路径；声明 KPipeWire 6.7 最低版本。
- 录音进程未使用的输出转到空设备，避免长录制积累诊断数据。
- 安装支持 --without-ocr，校验安装前缀并提前提示 uv 需求；OCR 安装强制依赖哈希。
- 公开文档与本地开发历史分开，安装／卸载和文档检查纳入 ctest。

## 0.4.1 · 2026-10-26

- 马赛克改为 Qt 纹理画笔涂抹，支持圆头轨迹和单点，独立直径 8～128，沿用撤销／重做。
- 马赛克菜单只显示粗细；移除颜色选项。按下时生成预览纹理，移动期间复用。
- 标注记录原选区裁切，修复预览与导出边缘不一致、扩大选区后暴露隐藏笔迹。
- 修复取色后笔刷色板不同步；快捷键切工具同步关闭旧菜单，清理无效点击连接。

## 0.4.0 · 2026-10-26

- 工具栏按编辑、识别、确认分组；录音选项与次要操作收进小菜单。
- 移除文字全文和识图结果按钮；OCR／译文统一跨框选择，长文字就地展开，识图卡片自动定位。
- 文字与取色偏好移到相邻小箭头，直接修改并记住；设置精简为三页。
- 保留独立字体与图片导出边界，修正中文译文首行裁切、阅读选择失效和菜单销毁顺序。
- 工具栏独立为 EditorToolbar，结果显示只订阅 Document，移除 Application 中的旧面板调度。
