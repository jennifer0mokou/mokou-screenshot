# 版本记录

## 0.4.3 · 2026-10-26

- 修复文字末尾方向键跳转、已有选择的收拢行为，以及展开文字误点到遮盖内容。
- OCR、翻译和识图结果分别按设置失效，切换 OCR 保留无关的识图结果。
- 合并编辑通知与译文查询，删除未使用接口和过时检查；安装只构建应用目标。
- 精简重复文档，清理旧构建、安装暂存与重复源码副本。

## 0.4.2 · 2026-10-26

- 统一命名 Mokou Screenshot，迁移桌面 ID、配置、环境变量与 OCR 目录。
- 准备 MIT 源码发布、第三方许可、贡献入口、Fedora CI 与发布流程。
- 去除检查中的固定 Python 路径，明确 KPipeWire 最低版本，限制录音诊断输出积累。
- 安装支持 --without-ocr，依赖使用哈希锁定，安装／卸载与文档检查纳入 ctest。

## 0.4.0～0.4.1 · 2026-10-26

分组工具栏、原位跨框选择、内嵌识图卡片与常用选项菜单；马赛克改为涂抹，标注统一按创建时的选区裁切。

## 早期开发

建立 KDE Wayland 捕获、标注／拼图、剪切板、区域录屏、本地多语言 OCR 与纯文字翻译；修复坐标恢复、会话竞态、静止视频时长和高 DPI 合成等问题。
